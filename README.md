
# Superstore Sales Dashboard

Ye project maine Power BI me banaya hai. Isme Superstore ke sales data ka analysis kiya hai.

## Is Dashboard me kya hai:
- Total Sales, Profit aur Quantity
- Month-wise Sales Trend
- Category-wise aur Region-wise Sales
- Top Products

## Tools Used:
- Power BI
- Excel / CSV Data

## Files:
- Superstore.pbix - Power BI File
- Superstore_Dashboard.pdf - Dashboard PDF
